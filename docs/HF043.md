# HF-04.3

HF-04.3 adds two independent controls to HF-04.2.

1. **Mandatory Ardross A5 startup replay.** `startup_gate.py` constructs `A5Operator`; operator initialisation loads the exact frozen A5-V1 bundle, scores the 5,000 frozen Ardross coordinates, applies the frozen provisional and page-global final decision rules, and compares outputs with the frozen expected vectors. Missing replay files, probability drift above `1e-7`, or any provisional/final mismatch prevents startup.
2. **Separate HF-versus-historical V7.8 channel diagnostic.** `app.hf043_channel_diagnostic.compare_hf_to_historical` compares all 11 HF-generated channels with the historical replay arrays and writes CSV, JSON and per-channel absolute-difference images. It is diagnostic only and does not weaken the mandatory model-output replay gate.

The replay pack belongs under `frozen/a5_v1/replay/ardross/`. The supplied image arrays are included. Add the supplied `depth.csv`, `x.csv`, `y.csv`, `expected_probability.csv`, `expected_provisional.csv`, and `expected_final.csv` with those exact names before deployment. This is intentionally fail-closed.
