# Proposed Challenger Experiment: Empirical Relaxation of the D3–D8 Development Envelope

**Purpose  
**Notebook 37 indicates that no tested PRINT threshold satisfies the current D3–D8 development envelope. Rather than immediately reducing thresholds further, the next experiment should determine whether elements of the envelope are over-conservative from a page-level perceptual perspective and quantify how much relaxation is possible before meaningful review risk emerges.

## Observed Result From Notebook 37

The threshold frontier suggests that the current envelope rejects all candidate operating points. The working hypothesis is not that lower thresholds are safe, but that some truth-defined catastrophic classifications may not correspond to perceptually catastrophic page outcomes.

## Core Scientific Question

Which D3–D8 envelope components are acting as useful safety controls, and which are excluding perceptually acceptable recovery of genuine print?

## Principle

Do not relax thresholds directly. Relax evaluation criteria under controlled review and measure the resulting perceptual impact.

## Proposed Experiment

Create a new development notebook that evaluates envelope sensitivity rather than threshold sensitivity. Generate candidate operating points that would fail exactly one envelope criterion at a time, while holding all others fixed.

## Experimental Arms

Arm A: Current envelope (control). Arm B: Relax catastrophic component definition. Arm C: Relax false/true ratio. Arm D: Relax false-preservation rate. Arm E: Relax utility lower-bound requirement. Arm F: Relax minimum benefit thresholds. Arm G: Combined best-performing relaxation.

## New Catastrophic Classification Framework

Replace the binary catastrophic/not-catastrophic definition with four classes: visually negligible, locally noticeable, reviewer-relevant, and operationally catastrophic. Human review should classify first-appearance components before gate calculations are recomputed.

## Required Outputs

Per-threshold review queues, component contact sheets, reviewer adjudications, page-level benefit estimates, source-group stability reports, recalculated frontier tables and sensitivity curves for each relaxed envelope configuration.

## Success Criteria

Demonstrate a material increase in recovered genuine print while maintaining acceptable reviewer burden and without introducing operationally catastrophic failures.

## Decision Rules

If a relaxation yields increased print recovery and failures are consistently rated visually negligible or locally noticeable, that relaxation becomes a candidate for preregistered independent testing. If failures are reviewer-relevant or operationally catastrophic, retain the existing gate.

## Recommended Next Notebook

Notebook 38 – Envelope Relaxation and Perceptual Severity Calibration.

## Expected Outcome

The likely outcome is not a lower PRINT threshold. The likely outcome is a refined definition of failure severity that allows additional print recovery without compromising practical page quality.

## Proposed Relaxation Ladder

- Level 0: Existing D3–D8 envelope (control).
- Level 1: Reclassify perceptually negligible catastrophes.
- Level 2: Recompute frontier metrics using severity-weighted catastrophes.
- Level 3: Test modified false-preservation targets.
- Level 4: Test modified utility requirements.
- Level 5: Evaluate combined envelope.
- Level 6: Freeze revised envelope and run a fresh preregistered challenger.
